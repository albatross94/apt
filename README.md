# 아파트 실거래가 분석

공공데이터포털의 **국토교통부 아파트 매매 실거래가** 데이터를 받아서, 단지·전용면적별 거래를 `실거래가 확인 리포트` 형식으로 보여 주는 웹 페이지입니다. 외부 패키지 없이 Node.js만으로 동작합니다.

## 주요 기능

- **시군구 조회**: 전국 256개 시군구 중에서 고르고, 시작월~종료월(최대 36개월)을 지정해 조회
- **시군구·거래 종류 조회**: 전국 256개 시군구 중에서 고르고, 거래 종류(매매·전세·월세)와 시작월~종료월(최대 36개월)을 지정해 조회. 조회 후 아파트명을 고름
- **리포트 화면**: 고른 단지를 아래 순서로 보여 줌
  1. **전용면적 선택** — 면적마다 가격대가 다르므로 같은 면적끼리만 비교. 전용면적(소수 둘째 자리)별 칩에 지금 탭의 건수를 표시하고, 거래가 가장 많은 면적이 먼저 선택됨
  2. **거래 종류 탭** — 매수인용·매매 / 임차인용·전세 / 임차인용·월세 / 공시가격 / 단지비교. 전월세는 같은 지역·기간으로 처음 열 때 추가로 불러옴
     - 매매: 거래 건수, 중간값, 가장 낮은·높은 거래, 최근 3개월 중간값, 계약일–가격 점 그래프
     - 전세: 거래 건수, 중간값, 신규·갱신 계약 중간값(3건 미만이면 "표본 부족"), 매매 대비 전세가율, 계약일–보증금 점 그래프(갱신은 속이 빈 점)
     - 월세: 거래 건수, 신규·갱신 건수, 보증금 범위, 보증금–월세 점 그래프, 보증금 구간별 월세 표
     - 공시가격: 국토교통부 공동주택가격(V-World)을 동·호·층·전용면적·공시가격 표로 보여 줌. 탭을 열면 자동으로 필지를 찾아 불러오고, 기준연도(2006년~)와 동·전용면적·호로 거를 수 있으며 열 제목을 눌러 정렬. 이 탭에서는 전용면적 칩과 거래 목록을 숨김
     - 단지비교: 조회한 지역·기간 안에서 단지를 최대 4개까지 골라 나란히 비교. 단지마다 전용면적(자료 그대로)을 따로 선택하며, 기본값은 거래가 가장 많은 면적. 준공연도, 매매(건수·중간값·전용 평당가·최저~최고·최근 3개월), 전세(건수·중간값·전세가율), 월세(건수·보증금·월세 중간값)를 표로 보여 주고 매매·전세·월세 가격 추이(월별 중간값, 월세는 월세 기준)를 단지별 선 그래프로 그림. 3건 미만은 "표본 적음" 표시. 다른 지역 단지와는 비교할 수 없고 공시가격은 포함하지 않음. 이 탭에서도 전용면적 칩과 거래 목록을 숨김
     - **PDF 저장**: 모든 탭에서 "이 탭 PDF로 저장"을 누르면 고객 성함(필수)과 연락처(선택)를 입력받고, 브라우저 인쇄 창(대상: PDF로 저장)으로 현재 탭을 저장. 파일명은 `거래유형_고객명_저장일`(예: `매매_홍길동_20261025.pdf`). 조회 조건·탭·버튼과 "그래프에 쓴 거래 목록"은 빼고 단지명 아래에 고객명·연락처·저장일시(시각까지) 줄을 넣고, 브라우저가 붙이는 머리글·바닥글(날짜·파일명)은 나오지 않게 하며(연락처는 파일명에 넣지 않음), 다크 모드여도 밝은 색으로 출력. 별도 라이브러리 없이 브라우저 인쇄 기능을 쓰므로 브라우저에 따라 기본 파일명이 다르게 나올 수 있음
  3. **현재 호가와 실거래 비교** (매매·전세·월세 탭) — 호가를 직접 입력하면 같은 단지·고른 전용면적의 최근 6개월 실거래 중간값과의 차액·비율, 호가의 위치, 유사 거래 8건과 비교. 입력값은 저장·전송하지 않고 탭마다 따로 기억
  4. **그래프에 쓴 거래 목록** — 계약일·동·층·금액·거래 방식·상태 (매매·전세·월세 탭)
  5. **이 자료를 믿고 보실 수 있는 근거** — 출처, 조회 조건, 자료 기준, 가공 방법

> 엑셀 내보내기는 화면에서 뺐습니다.

## 준비물

- [Node.js](https://nodejs.org) 18 이상
- 공공데이터포털([data.go.kr](https://www.data.go.kr)) 인증키: "국토교통부_아파트 매매 실거래가 자료"와 (전세·월세용) "국토교통부_아파트 전월세 실거래가 자료"를 검색해 각각 활용신청한 뒤, 마이페이지에서 **일반 인증키**를 복사 (활용신청 직후에는 반영까지 시간이 걸릴 수 있음)
- (공시가격 탭을 쓰려면) [V-World](https://www.vworld.kr) 인증키: 마이포털의 인증키 관리에서 발급받고, 활용 API에 국가중점데이터(NED) API가 포함되도록 신청

## 실행 방법

1. `.env.example`을 `.env`로 복사하고 `SERVICE_KEY=` 뒤에 인증키를 붙여넣습니다. `=` 앞뒤에 공백이나 따옴표는 넣지 않습니다. 인코딩된 키와 디코딩된 키 모두 사용할 수 있습니다.

   ```
   SERVICE_KEY=발급받은_인증키
   VWORLD_KEY=발급받은_V-World_인증키
   ```

   `APP_PASSWORD=비밀번호`를 적으면 첫 화면에 로그인이 생깁니다(비워 두면 로그인 없이 열림).
   `VWORLD_KEY`는 공시가격 탭에만 필요합니다. 없어도 나머지 기능은 동작하고, 공시가격 탭을 열면 키가 설정되지 않았다는 안내가 나옵니다.

2. 서버를 실행합니다.

   - Windows: `start.bat`을 더블클릭 (브라우저가 자동으로 열림)
   - 터미널: `node server.js` 실행 후 http://localhost:3000 접속

   포트를 바꾸려면 `PORT` 환경변수를 지정합니다.

3. 시군구와 기간을 고르고 **조회**를 누릅니다. 조회가 끝나면 아파트명 드롭다운이 켜집니다.

## Vercel에 배포

`public/`(화면)과 `api/`(서버리스 함수)를 그대로 배포할 수 있습니다. 로컬의 `server.js`는 Vercel에서는 쓰이지 않습니다.

1. 이 저장소를 GitHub에 올린 뒤 [vercel.com/new](https://vercel.com/new)에서 **Import** 합니다. 빌드 설정은 `vercel.json`에 들어 있어 그대로 두면 됩니다. (Framework Preset: Other)
2. 배포 전에 프로젝트의 **Settings → Environment Variables**에 인증키를 추가합니다. 이름은 `.env`와 같습니다.

   | 이름 | 값 | 용도 |
   |---|---|---|
   | `SERVICE_KEY` | 공공데이터포털 인증키 | 실거래가 |
   | `RENT_SERVICE_KEY` | (선택) 전월세 API 전용 인증키. 없으면 `SERVICE_KEY` 사용 | 전세·월세 |
   | `VWORLD_KEY` | V-World 인증키 | 공시가격 탭 (선택) |
   | `APP_PASSWORD` | 로그인 비밀번호(공용 1개) | **배포할 때는 반드시 설정.** 비워 두면 로그인 없이 열림 |

3. **Deploy** 합니다. 키를 나중에 바꾸면 환경 변수를 수정한 뒤 다시 배포해야 적용됩니다.

CLI로 하려면 `npm i -g vercel` 후 `vercel`(미리보기) / `vercel --prod`(운영)을 실행하고, 키는 `vercel env add SERVICE_KEY`처럼 추가합니다.

**알아두실 점**
- **로그인**: 첫 화면이 비밀번호 로그인입니다. `APP_PASSWORD`와 같은 비밀번호를 입력하면 7일 동안 유지되는 로그인 쿠키(서명, HttpOnly)가 발급되고, 화면의 **로그아웃** 버튼으로 끝낼 수 있습니다. 실거래가·공시가격 API도 로그인한 요청만 처리하므로(`401`), 주소를 알아도 인증키 호출 한도를 쓸 수 없습니다. 비밀번호를 바꾸면 기존 로그인은 모두 풀립니다. 사용자별 계정은 없고 공용 비밀번호 하나입니다. 틀린 비밀번호에는 응답을 0.8초 늦춥니다.
- **`APP_PASSWORD`를 설정하지 않으면 누구나 접속할 수 있습니다.** Vercel에 배포할 때 빠뜨리지 마세요. 환경 변수를 바꾼 뒤에는 다시 배포해야 적용됩니다.
- 로그인을 붙이면서 API 응답은 CDN(공유 캐시)에 두지 않고 브라우저에만 5분 캐시합니다(`private`). CDN에 두면 로그인하지 않은 사람에게도 응답이 나갈 수 있기 때문입니다. 외부 API 호출을 줄이는 일은 서버 쪽 파일 캐시가 맡습니다.
- Vercel에는 영구 디스크가 없어서 `cache/`는 쓰지 않고, 함수 인스턴스의 임시 폴더(`/tmp`)만 보조로 씁니다. 그래서 Vercel에서는 인스턴스가 바뀌면 같은 달도 외부 API를 다시 호출할 수 있고, 이전보다 호출이 늘 수 있습니다.
- 실거래가는 한 번에 한 달씩 요청하고(화면이 4개씩 동시에 보냄) 함수 실행 시간 제한을 넉넉히 잡아 두었습니다(`maxDuration: 60`). 요금제에 따라 허용되는 최대 시간이 다르니, 한도에 걸리면 Vercel 대시보드에서 확인하세요.
- 공시가격에서 V-World 인증 오류가 나면 V-World 마이포털의 인증키에 등록된 **서비스 URL**에 배포 주소를 추가해 보세요.

## 동작 방식

인증키가 브라우저로 노출되지 않도록, 그리고 받은 결과를 캐시해 호출 횟수를 줄이도록 서버 쪽에서 외부 API를 대신 호출합니다. 처리 로직은 `lib/core.js` 한 곳에 있고, 로컬 서버(`server.js`)와 Vercel 함수(`api/*.js`)가 같이 씁니다.

```
브라우저 ──/api/trades──▶ lib/core.js ──▶ apis.data.go.kr (RTMSDataSvcAptTrade)
   ▲     ──/api/gongsi/*─▶     │      └──▶ api.vworld.kr   (주소 검색, 공동주택가격)
   └── public/index.html ◀─────┘  결과 캐시: 로컬은 cache/, Vercel은 CDN
```

- 호출하는 API는 `RTMSDataSvcAptTrade/getRTMSDataSvcAptTrade`(매매)와 `RTMSDataSvcAptRent/getRTMSDataSvcAptRent`(전월세, `type=rent`)입니다. 전세·월세는 월세 유무로 나눕니다.
- 한 달 치를 지역 코드(`LAWD_CD`)별로 페이지를 넘기며 모두 받아 `cache/지역코드_YYYYMM.json`에 저장합니다. 지난 달은 영구 캐시, 이번 달은 1시간만 캐시합니다.
- 해제(취소)된 거래는 분석에서 제외합니다.
- 공시가격은 선택한 단지의 시도·시군구·법정동·지번으로 V-World 주소 검색에서 필지번호(PNU)를 얻고, 그 PNU로 `getApartHousingPriceAttr`를 호출해 가져옵니다. 연도별 결과는 `cache/`에 저장되며, 올해 자료는 7일, 지난 연도는 영구 캐시합니다.
- 화면은 D3.js로 그립니다. 라이브러리를 CDN에서 불러오므로 인터넷 연결이 필요합니다.

## 알아두실 점

- **면적은 전용면적 기준**입니다. API에 공급면적이 없어서 전용면적을 소수 둘째 자리까지 그대로 구분해 보여 줍니다(예: 84.43㎡와 84.97㎡는 서로 다른 칩). 평수는 전용면적을 3.3058로 나눈 값입니다.
- **시군구 코드는 최신 행정개편 기준**입니다. 광주·전남 통합(12xxx), 인천 구 개편, 화성시 구 신설 등이 반영돼 있고, 예전 코드(예: 46110)로는 데이터가 오지 않습니다.
- 처음 조회하는 기간은 API를 여러 번 호출하므로 수십 초 걸릴 수 있습니다. 한 번 받은 달은 캐시되어 다음부터 빠릅니다.
- 같은 이름의 단지가 한 지역에 여러 개 있을 수 있어, 아파트명 드롭다운은 법정동과 함께 표시합니다.
- **공시가격은 필지(지번) 기준**으로 조회합니다. 한 필지에 단지가 여러 개면 함께 나오고, 실거래 자료에 지번이 없는 단지는 조회할 수 없습니다. 같은 동·호가 중복으로 내려오는 경우가 있어 하나로 합쳐서 보여줍니다. 가격은 만원 단위입니다.

## 폴더 구성

```
server.js            로컬 실행용 서버 (API 라우팅 + 정적 파일)
start.bat            Windows용 실행 파일
lib/core.js          데이터 처리 공통 로직 (실거래가·공시가격 호출, 캐시, 라우팅)
lib/auth.js          공용 비밀번호 로그인 (서명 쿠키 세션)
api/                 Vercel 서버리스 함수 (lib/core.js·lib/auth.js를 호출)
vercel.json          Vercel 배포 설정
package.json         Node 버전 지정, npm start
.vercelignore        Vercel 배포에서 제외할 파일
public/index.html    화면 (실거래가 확인 리포트)
public/regions.json  전국 시군구 코드 목록
cache/               조회 결과 캐시 (자동 생성, git 제외)
.env                 인증키 (직접 생성, git 제외)
.env.example         인증키 견본
```
