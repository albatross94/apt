# 아파트 실거래가 분석

공공데이터포털의 **국토교통부 아파트 매매 실거래가** 데이터를 받아서, 단지별로 가격 흐름을 보고 여러 단지를 비교하는 웹 페이지입니다. 외부 패키지 없이 Node.js만으로 동작합니다.

## 주요 기능

- **시군구 조회**: 전국 256개 시군구 중에서 고르고, 시작월~종료월(최대 36개월)을 지정해 조회
- **단지 상세**: 단지를 고르면 평형별 평균가, 월별 평균 거래가, 월·연도 겹쳐보기, 연도별 평균, 월별 거래 건수, 요약표, 거래 내역을 보여줌. 상단 칩으로 평형을 바꾸면 모든 그래프와 표가 따라 바뀜
- **단지 비교**: 단지를 최대 8개까지 담아 같은 평형 기준으로 비교. 시군구가 달라도 됨. 지표는 거래가 또는 전용 평당가. 비교 목록은 새로고침해도 유지됨
- **동·호별 공시가격** (선택): 단지 상세 화면에서 [공시가격 조회]를 누르면 국토교통부 공동주택가격(V-World) 자료를 동·호·층·전용면적·공시가격 표로 보여줌. 2006년부터 연도별로 선택할 수 있고, 동·평형으로 거르고 정렬하고 엑셀로 저장할 수 있음
- **엑셀 내보내기**: 상세·비교·공시가격 화면 모두 `.xlsx`로 저장

## 준비물

- [Node.js](https://nodejs.org) 18 이상
- 공공데이터포털([data.go.kr](https://www.data.go.kr)) 인증키: "국토교통부_아파트 매매 실거래가 자료"를 검색해 활용신청한 뒤, 마이페이지에서 **일반 인증키**를 복사 (활용신청 직후에는 반영까지 시간이 걸릴 수 있음)
- (공시가격을 쓰려면) [V-World](https://www.vworld.kr) 인증키: 마이포털의 인증키 관리에서 발급받고, 활용 API에 국가중점데이터(NED) API가 포함되도록 신청

## 실행 방법

1. `.env.example`을 `.env`로 복사하고 `SERVICE_KEY=` 뒤에 인증키를 붙여넣습니다. `=` 앞뒤에 공백이나 따옴표는 넣지 않습니다. 인코딩된 키와 디코딩된 키 모두 사용할 수 있습니다.

   ```
   SERVICE_KEY=발급받은_인증키
   VWORLD_KEY=발급받은_V-World_인증키
   ```

   `VWORLD_KEY`는 공시가격 기능에만 필요합니다. 없어도 나머지 기능은 동작하고, 공시가격을 조회하면 키가 설정되지 않았다는 안내가 나옵니다.

2. 서버를 실행합니다.

   - Windows: `start.bat`을 더블클릭 (브라우저가 자동으로 열림)
   - 터미널: `node server.js` 실행 후 http://localhost:3000 접속

   포트를 바꾸려면 `PORT` 환경변수를 지정합니다.

3. 시군구와 기간을 고르고 **조회**를 누릅니다. 조회가 끝나면 아파트명 드롭다운이 켜집니다.

## 동작 방식

인증키가 브라우저로 노출되지 않도록, 그리고 받은 결과를 캐시해 호출 횟수를 줄이도록 `server.js`가 외부 API를 대신 호출합니다.

```
브라우저 ──/api/trades──▶ server.js ──▶ apis.data.go.kr (RTMSDataSvcAptTrade)
   ▲     ──/api/gongsi/*─▶     │    └──▶ api.vworld.kr   (주소 검색, 공동주택가격)
   └── public/index.html ◀─────┘  결과를 cache/ 에 저장
```

- 호출하는 API는 `RTMSDataSvcAptTrade/getRTMSDataSvcAptTrade`(기본 API)입니다.
- 한 달 치를 지역 코드(`LAWD_CD`)별로 페이지를 넘기며 모두 받아 `cache/지역코드_YYYYMM.json`에 저장합니다. 지난 달은 영구 캐시, 이번 달은 1시간만 캐시합니다.
- 해제(취소)된 거래는 분석에서 제외합니다.
- 공시가격은 선택한 단지의 시도·시군구·법정동·지번으로 V-World 주소 검색에서 필지번호(PNU)를 얻고, 그 PNU로 `getApartHousingPriceAttr`를 호출해 가져옵니다. 연도별 결과는 `cache/`에 저장되며, 올해 자료는 7일, 지난 연도는 영구 캐시합니다.
- 화면은 D3.js로 그리고, 엑셀은 SheetJS로 브라우저에서 만듭니다. 두 라이브러리는 CDN에서 불러오므로 인터넷 연결이 필요합니다.

## 알아두실 점

- **평형은 전용면적 기준**입니다. API에 공급면적이 없어서, 단지 안에서 전용면적이 1.5㎡ 이내로 가까운 것끼리 한 평형으로 묶고 소수점을 버려 표시합니다(예: 84.43㎡와 84.97㎡는 "84㎡"). 평수는 전용면적을 3.3058로 나눈 값입니다.
- **시군구 코드는 최신 행정개편 기준**입니다. 광주·전남 통합(12xxx), 인천 구 개편, 화성시 구 신설 등이 반영돼 있고, 예전 코드(예: 46110)로는 데이터가 오지 않습니다.
- 처음 조회하는 기간은 API를 여러 번 호출하므로 수십 초 걸릴 수 있습니다. 한 번 받은 달은 캐시되어 다음부터 빠릅니다.
- 같은 이름의 단지가 한 지역에 여러 개 있을 수 있어, 아파트명 드롭다운은 법정동과 함께 표시합니다.
- 비교 목록은 브라우저(`localStorage`)에 단지 정보만 저장합니다. 같은 브라우저·같은 주소에서만 유지됩니다.
- **공시가격은 필지(지번) 기준**으로 조회합니다. 한 필지에 단지가 여러 개면 함께 나오고, 실거래 자료에 지번이 없는 단지는 조회할 수 없습니다. 같은 동·호가 중복으로 내려오는 경우가 있어 하나로 합쳐서 보여줍니다. 가격은 만원 단위입니다.

## 폴더 구성

```
server.js            API 프록시 + 정적 파일 서버
start.bat            Windows용 실행 파일
public/index.html    분석 화면 (단지 상세·비교·공시가격·엑셀 내보내기)
public/regions.json  전국 시군구 코드 목록
cache/               조회 결과 캐시 (자동 생성, git 제외)
.env                 인증키 (직접 생성, git 제외)
.env.example         인증키 견본
```
